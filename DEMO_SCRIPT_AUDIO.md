## DEFENCE Q&A CHEAT SHEET

**Q: Why did you use JSON file instead of a real database?**
"A: For simplicity and zero configuration. The abstraction layer makes it easy to swap to PostgreSQL or MongoDB in production."

**Q: How does the AI classification work?**
"A: It uses Google Gemini API to analyse waste images. If the API key is not configured, a heuristic fallback uses keyword matching from the description."

**Q: Is the system secure?**
"A: Role-based access control ensures each user only sees what they need. In production, passwords would be hashed with bcrypt and sessions managed with JWT tokens."

**Q: Can this scale to the whole university?**
"A: Yes. The backend is stateless and can be horizontally scaled. The JSON database can be replaced with a proper RDBMS. Docker support enables containerised deployment."

**Q: What did you learn from this project?**
"A: Full-stack web development, RESTful API design, AI integration, role-based access control, and real-time data management."
